# GhanaCart — GitHub Pages Edition

This package is prepared for GitHub Pages. `index.html` is at the repository root and `.nojekyll` is included so the complete static asset tree is published.

## Included
- Branded 20M+ virtual SKU catalog
- Local product/accessory image library
- Search, categories, product pages, cart, favorites and orders
- Ghana Cedi pricing
- Paystack frontend checkout integration
- Responsive multi-page layout
- Back buttons, favicon and animated trending products

## GitHub Pages
See `GITHUB_PAGES_SETUP.md` for the exact upload and Pages settings.
