# GhanaCart — GitHub Pages Setup

## Upload
Upload the **contents of this folder** to the root of your GitHub repository. `index.html` must be in the repository root.

## Enable GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save and wait for GitHub to publish the site.

Your site will normally be available at:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
